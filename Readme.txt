## 🛠️ Prerequisites & Setup

Ensure you have a modern C++ compiler (supporting C++17 or later) or Python 3.x installed.

### C++ Compilation

```bash
g++ -std=c++17 -O2 filename.cpp -o main
./main

```

### Python Execution

```bash
python3 filename.py

```

## 📌 Topics Covered

* **Arrays & Matrices:** Searching, rotation, two-pointer techniques, sliding window.
* **Linked Lists:** Singly, doubly, and circular linked lists with common operations.
* **Stacks & Queues:** Array/LL implementations, monotonic stacks, priority queues.
* **Trees & Graphs:** Binary Trees, BSTs, Traversals (DFS/BFS), Shortest Path (Dijkstra, Bellman-Ford).
* **Algorithms:** Divide & Conquer, Dynamic Programming, Greedy approaches.
